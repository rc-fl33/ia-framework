# Migration & Data Movement Tools

**Purpose:** Manage framework restructuring, data migrations, and archive operations

## Scripts

- `backup-resources.py` - Create backup snapshots of resource directories
- `migrate-framework-structure.py` - Restructure framework directories
- `archive-old-content.py` - Archive deprecated content and maintain history

## Recent Migrations

- **2026-01-03:** Google Drive PDF sync - synced missing frameworks and books from Google Drive
- **Phase 6.x:** Library restructuring - simplified resource architecture from 4-5 levels to 2-level flat structure

## Usage

Migration scripts are primarily used during framework restructuring phases. Regular use not required.

## Safety

All migration scripts create backups before operations and verify results.
