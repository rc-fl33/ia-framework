Finding Blocks

F-001: SQL Injection in Authentication Endpoint

The /api/login endpoint accepts unsanitized input in the username parameter, allowing complete authentication bypass.

CVSS 9.8 · CVE-2021-44228 · Status: Open

F-002: Stored Cross-Site Scripting in Dashboard

User-supplied content is rendered without output encoding in the activity dashboard, enabling persistent XSS.

CVSS 7.4 · Status: Open

F-003: Insecure Direct Object Reference

The document download endpoint exposes predictable identifiers without authorization checks.

CVSS 5.3 · Status: In Progress

F-004: Missing Security Headers

CSP, HSTS, and X-Frame-Options headers are absent, reducing defense-in-depth.

CVSS 3.1 · Status: Open

F-005: TLS 1.1 Supported

The server accepts TLS 1.1 connections. Consider disabling deprecated protocol versions.

Informational · Status: Open
