# ISO 19011 - Guidelines for Auditing Management Systems

**Place official standard PDF here:**
- `ISO-19011.pdf`

**What this standard contains:**
- Generic auditing criteria for all ISO management systems
- Auditor competency requirements
- Audit program management guidelines

**Priority:** LOW - Generic standard, applies to all ISO MSS
**Source:** https://www.iso.org/standard/70017.html

**Note:** This is a general auditing standard that applies to ISO 42001 the same
way it applies to ISO 27001, ISO 9001, etc. Not AI-specific.
