# Deliverables

This directory holds assessment deliverables generated during the analysis and reporting phase.

Deliverables are produced from dedicated templates located in the AIUC-1 framework template directory:

- **compliance-matrix.md** -- Generated from `frameworks/aiuc-1/templates/deliverables/compliance-matrix.md`. Per-requirement compliance status with scoring across all 51 AIUC-1 requirements.

- **findings-report.md** -- Generated from `templates/deliverables/phase-findings-template.md` (adapted for AIUC-1 principles). Consolidated findings by principle with gap analysis and recommendations.

- **remediation-plan.md** -- Generated from `frameworks/aiuc-1/templates/deliverables/remediation-plan.md`. Prioritized action plan with owners, timelines, and effort estimates.

- **certification-readiness.md** -- Generated only when Schellman certification is in scope. Readiness assessment against AIUC-1 certification audit requirements.

These files are populated by the compliance agent during the deliverable generation phase. Do not create them manually.
