1. **Physical Security Managers** - Responsible for implementing Requirement 9 controls
2. **Compliance Teams** - Preparing for PCI DSS assessment and evidence collection
3. **Facilities Managers** - Badge systems, visitor management, media storage
4. **IT Security Teams** - Integrating physical and logical security
5. **Internal Auditors** - Validating Requirement 9 compliance before external assessment

1. **Initial Assessment:** Read Executive Summary + Control Family sections to understand scope
