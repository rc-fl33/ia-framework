# Mentorship Skill

**Structured learning roadmaps with certification guidance and progress tracking.**

---

## Quick Start

```bash
# Learning roadmap for a skill
/mentorship learn penetration testing

# Certification prep
/mentorship prepare for OSCP

# Career progression
/mentorship advance to senior security engineer
```

---

## What This Skill Does

Creates personalized 30/60/90-day learning plans with:
- Skills assessment and gap analysis
- Free-first platform recommendations
- Certification ROI analysis
- Progress tracking templates

---

---

## Philosophy

- **Free First** - Prioritize free platforms before paid options
- **Hands-On** - Labs and practice over lectures
- **ROI-Focused** - Only recommend certs with proven market value
- **Portfolio > Certs** - Real projects demonstrate skills better
