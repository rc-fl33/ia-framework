# Mentorship Skill Verification

**Use this checklist to verify skill execution quality.**

---

## Pre-Execution Checklist

- [ ] SKILL.md read completely
- [ ] Mode detected (Learning Roadmap / Certification Prep / Portfolio / Career Progression)
- [ ] Target goal identified
- [ ] Timeline determined (30/60/90 days)

---

## Phase Verification

### Phase 1: ASSESS

- [ ] Current skills documented
- [ ] Target goal clearly defined
- [ ] Gap analysis completed
- [ ] Constraints captured (budget, time, prerequisites)
- [ ] Learning style preference noted

### Phase 2: PLAN

- [ ] 30-day foundation phase defined
- [ ] 60-day building phase defined
- [ ] 90-day application phase defined
- [ ] Weekly objectives set
- [ ] Milestone checklists created

### Phase 3: RESOURCE

- [ ] WebSearch used for current pricing/info
- [ ] Free platforms prioritized
- [ ] Paid options listed with costs
- [ ] Certification ROI analyzed (if applicable)
- [ ] Communities identified

### Phase 4: TRACK

- [ ] Progress tracker created
- [ ] Milestones listed with checkboxes
- [ ] Session log template included
- [ ] metadata.json created

---

## Output Verification

### Required Files (Exactly 4)

```
private/output/mentorship/{Goal}-{YYYY-MM-DD}/
├── metadata.json           ✓
├── LEARNING-ROADMAP.md     ✓
├── RESOURCES.md            ✓
└── PROGRESS-TRACKER.md     ✓
```

- [ ] All 4 files present
- [ ] No extra files created
- [ ] Correct output folder path

### Content Quality

**LEARNING-ROADMAP.md:**
- [ ] Clear 30/60/90 structure
- [ ] Specific weekly objectives
- [ ] Actionable deliverables
- [ ] Realistic timeline given constraints

**RESOURCES.md:**
- [ ] Free platforms listed first
- [ ] Current pricing (WebSearch verified)
- [ ] ROI analysis for certifications
- [ ] Communities included

**PROGRESS-TRACKER.md:**
- [ ] All milestones from roadmap
- [ ] Session log template
- [ ] Skills progression table
- [ ] Projects tracking section

**metadata.json:**
- [ ] Valid JSON format
- [ ] All required fields present
- [ ] Correct dates and counts

---

## Common Mistakes

| Mistake | Prevention |
|---------|------------|
| Outdated cert pricing | Always use WebSearch |
| Too many objectives | Max 5 per phase |
| Missing free options | Free platforms FIRST |
| No ROI analysis | Required for any cert recommendation |
| Extra files created | Only 4 files per spec |

---

## Quality Standards

- [ ] Free resources prioritized over paid
- [ ] Certifications only if ROI-positive
- [ ] Timeline realistic for user's constraints
- [ ] Actionable, specific milestones
- [ ] WebSearch used for current data
