## Prompt Engineering Guide

### Effective Prompt Structure

**Template:**
```
[Subject] in [Style] style, [Composition details],
[Color palette], [Background], [Perspective/Angle],
[Aspect ratio], [Quality notes]
```

**Example:**
```
Authentication flow diagram in technical illustration style,
clean modern design with boxes and arrows, blue and gray color scheme,
white background, isometric perspective, 16:9 aspect ratio,
high detail and clarity
```

### Prompt Components

**Subject (What):**
- Be specific about the main focus
- Include key elements to be visualized
- Mention any relationships or connections

**Style (How):**
- Reference aesthetic category
- Mention artistic approach
- Specify rendering type

**Composition (Arrangement):**
- Layout preferences
- Element positioning
- Spacing and balance

**Colors (Palette):**
- Specific color names or hex codes
- Overall color mood
- Background preferences

**Technical (Specs):**
- Aspect ratio
- Perspective/angle
- Quality requirements

## Quality Standards

### Image Quality Checklist
- [ ] **Clarity** - Main subject clearly visible and recognizable
- [ ] **Style consistency** - Matches aesthetic template
- [ ] **Color accuracy** - Uses defined palette
- [ ] **Composition** - Well-balanced and intentional layout
- [ ] **Technical quality** - High resolution, no artifacts
- [ ] **Brand alignment** - Reflects brand values and identity
- [ ] **Relevance** - Enhances content understanding

### Rejection Criteria
**Regenerate if image has:**
- ❌ Incorrect style (doesn't match template)
- ❌ Wrong colors (outside defined palette)
- ❌ Poor composition (cluttered, unbalanced)
- ❌ Low quality (pixelated, artifacts)
- ❌ Irrelevant content (doesn't support topic)
- ❌ Text errors (garbled or incorrect text in image)

## Image Integration Guidelines

### Placement in Content
- **Hero image:** Top of article, sets tone
- **Section breaks:** Between major sections for visual relief
- **Inline:** Within sections to illustrate specific points
- **Gallery:** Multiple related images together

### Sizing & Formatting
- **Full width:** Featured images, diagrams
- **Inline:** Smaller images within text
- **Thumbnails:** Previews, galleries

### Alt Text & Captions
**Alt text (accessibility):**
- Describe what the image shows
- Keep under 125 characters
- Focus on content, not style

**Captions (context):**
- Explain significance or relationship to content
- Add value beyond alt text
- Optional but recommended
